# NOWA Technologies — Production Website

Multi-page static website for NOWA Technologies.

## Pages
- `index.html` — Home
- `about.html` — About
- `services.html` — Services
- `work.html` — Work
- `process.html` — Process
- `contact.html` — Contact

## Visual and motion system
- Orange / black NOWA identity
- Responsive section-driven layouts
- Progressive scroll text fill
- Smooth scrolling with native fallback
- Three.js hero orb with CSS/WebGL fallback
- Magnetic buttons, custom cursor, parallax and page transitions
- Reduced-motion accessibility support

## Local preview
Open the project folder with VS Code Live Server and start from `index.html`.

## Asset provenance
- NOWA logo files are project brand assets supplied for this website.
- No BYTRIX images, videos, copy, contact details, hosted assets, CSS files or JavaScript files are included in this build.
- Previously supplied Gilmer font binaries are not distributed in this build. The site uses Manrope from Google Fonts with system-font fallback.
- Third-party runtime libraries and their licenses are listed in `THIRD_PARTY_NOTICES.md`.

## Launch note
The contact form is front-end only until connected to a mail service or backend endpoint.
