# NOWA Technologies — Animated Website

A clean, original one-page website inspired by the interaction style of the supplied reference source and rebuilt for NOWA Technologies in a orange-and-black visual system.

## Included

- Animated page loader
- Custom desktop cursor
- Scroll progress indicator
- Full-screen animated menu
- Large kinetic hero typography
- Scroll reveal and text-fill animations
- Parallax background elements
- Interactive services section
- Animated technology cloud
- Pinned horizontal project showcase on desktop
- Animated counters
- Process hover effects
- Contact modal with front-end validation
- Responsive mobile layouts
- Reduced-motion accessibility support
- Local Gilmer font files and optimized NOWA logo variants

## Run locally

Open a terminal in this folder and run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before production

1. Replace placeholder project names, stats, testimonial and social links.
2. Update `hello@nowatechnologies.com` if your final email is different.
3. Connect the contact form in `assets/js/app.js` to your preferred backend, Formspree, EmailJS or CRM.
4. Add your real privacy policy, analytics and SEO/social metadata.

The build is dependency-free and does not rely on the reference site's remote assets or obfuscated scripts.
